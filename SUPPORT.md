# Support

## Asking questions

- **Design questions** ("why does the skill prefer X over Y?", "how should I extend this for venue Z?") → open a [Discussion](https://github.com/OpenGHz/embodied-ai-paper-writer/discussions).
- **Bug reports** (a rule is wrong, a link is broken, a template fails) → open an [Issue](https://github.com/OpenGHz/embodied-ai-paper-writer/issues/new/choose).
- **Feature requests / new patterns** → open an [Issue](https://github.com/OpenGHz/embodied-ai-paper-writer/issues/new/choose) using the Pattern Suggestion template.
- **Security concerns** → see [`SECURITY.md`](SECURITY.md).

## Before you ask

- Search closed issues — your question may already have an answer.
- Check the section's playbook in [`references/`](references/) before opening an issue; many "this seems wrong" cases are actually documented edge cases.
- For "the skill didn't activate" reports: include the exact prompt you used and the version of Claude you ran it against.

## Response times

This is a community-maintained skill. Best-effort responses; no SLAs. Critical issues (incorrect rule that could mislead authors) are prioritized.

## What this project does NOT support

- General Claude / Anthropic API questions (ask Anthropic).
- Help writing a paper from scratch (use the skill; if it doesn't help, file a Pattern Suggestion).
- Reviews of your unpublished manuscript (please respect peer-review norms).
